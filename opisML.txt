Files

Columns
Column names are descriptive in Polish

data -> YY-MM-DD
święto -> bool
dzień_roboczy -> bool
pogoda -> text
temperatura -> int
odczuwalna_temperatura -> int
wilgotność -> int
prędkość_wiatru -> int
studenty_ms -> int (our target - number of students on Miasteczko Studenckie)

W wyniku serii niepokojących incydentów na miasteczku studenckim, władze jednej polskiej uczelni postanowiły działać bez zwłoki: trzeba było wzmocnić ochronę Miasteczka Studenckiego. Do tego odpowiedzialnego zadania wybrano firmę Gepard. To nowy gracz na rynku ochrony - pełen zapału, ale dopiero uczący się realiów studenckiego życia i tego, ile osób pojawia się tu w poszczególne dni tygodnia.

Gepard, choć ambitny, potrzebuje wiedzy. Dlatego zatrudnili Was - zespół programistów z jasnym celem: wytrenować model, który na podstawie kilku dostępnych danych będzie potrafił przewidzieć liczbę studentów w danym dniu. To rozwiązanie może zadecydować o skuteczności ochrony i o bezpieczeństwie całego miasteczka.

Na szczęście nie zaczynacie od zera, poprzednia firma zostawiła po sobie bogaty zasób informacji: dane z rozwiniętego systemu inwigilacji studentów. To skarbnica surowych sygnałów i wzorców, które, odpowiednio opracowane, pozwolą zbudować precyzyjny model przewidywania tłumów.

Stawka jest wysoka: dobrze wytrenowany model to nie tylko liczby na wykresie, to realny wpływ na bezpieczeństwo i spokój mieszkańców miasteczka. Macie narzędzia, dane i odpowiedzialność - teraz pora zamienić surowe dane w inteligentne prognozy, które pozwolą Gepardowi stać się strażnikiem, jakiego to miasteczko potrzebuje.

Evaluation
Submissions are evaluated on RMSLE between the predicted values and the observed target.

Submission File
For each ID in the test set, you must predict a TARGET variable. The file should contain a header and have the following format:

ID,TARGET
2,12
5,23
6,9
etc.
